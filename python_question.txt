What are Python Decorators?
Answer: Decorators are a design pattern that allows a user to modify or enhance the behavior of a function or class without permanently changing its source code. They are essentially functions that take another function as an argument, add some functionality, and return the modified function.
A decorator is the outer function that takes a function as an argument, defines a wrapper function to modify it, and returns the wrapper.
A wrapper is the inner function defined within a decorator that actually performs the added functionality (the code that runs before and/or after the original function call).
Use Cases: Performing testing, performing caching, checking permissions, logging, or timing function execution.
Example for Python Decorator:
Python
import time
import math

# decorator function
def calculate_time(func):

    def inner1(*args, **kwargs): # wrapper function

        # perform operation before function call
        begin = time.time()
        print("b",begin)

        func(*args, **kwargs) # call actual function

        # perform operation after function call
        end = time.time()
        print("e",end)
        print("Total time taken in : ", func.__name__, end - begin)
        return end - begin

    return inner1

@calculate_time # declare decorator for below function
def factorial(num):
    print(math.factorial(num))

print(factorial(5)) # calling the function.

What are generators, iterators, and iterables in Python?
Answer:
Iterable: An object that can be iterated over (e.g., in a for loop). This means it is any Python object capable of returning its members one at a time. Objects are iterable if they implement the __iter__() method. Examples include Lists, tuples, dictionaries, strings, and sets.
Iterator: An object that represents a stream of data and knows how to produce the next value when requested. An iterator consists of the methods __iter__() (which returns the iterator object itself) and __next__() (which returns the next item from the container). print(next(gen))  # Output: 2

Are access specifiers used in Python?
Answer: Python does not use access specifiers specifically like private, public, or protected in the same way as languages like Java or C++. Instead, it uses a convention based on prefixes:
Public: No prefix (accessible from anywhere).
Protected: Having a single underscore (_) before the variable/method name. This is a convention to indicate that it should not be accessed directly from outside the class or its subclasses, but it is not enforced.
Private: Having a double underscore (__) before the variable/method name. This triggers name mangling, which makes it harder (but not impossible) to access from outside the class, acting as a form of weak privacy enforcement.

What does *args and **kwargs mean?
Answer: These are special syntaxes used to pass a variable number of arguments to a function.
*args: Allows a function to accept any number of positional arguments (non-keyword arguments). These arguments are collected into a tuple inside the function.
**kwargs: Allows a function to accept a variable length of keyword arguments (arguments passed with a name, e.g., key=value). These arguments are collected into a dictionary inside the function.
Order of Arguments: When passing mixed arguments, the order must be: positional arguments -> *args -> keyword arguments -> **kwargs.
Example:
Python
def reverse(*args, **kwargs):
    for i in args:

    for i, j in kwargs.items():

# Keyword args (dict): {'kl': 'lk', 'har': 'rah', 'endl': 9}

What are the database connections in Python Flask, explain?
Answer:
Flask supports database-powered applications, but it does not include a built-in database layer. The relational database systems often need a schema, which might require piping a schema.sql file into a command-line utility like sqlite3.
Flask provides mechanisms to manage database connections throughout the request lifecycle, which are typically used with a database library (like SQLAlchemy or a raw driver):
before_request(): This function is called before the request is processed. It's often used to establish a database connection and store it on the global g object.
after_request(): This function is called after the request is processed and sends a response to the client. It can be used for actions like modifying the response, but it's generally not where you close the DB connection if an exception can occur.

Explain the procedure to minimize or lower the outages of the Memcached server in your Python development?
Answer: To minimize Memcached server outages and their impact on a Python application, several strategies can be employed:
Avoid Cache Stampedes (Dog-piling): When a single instance fails, the database can be hit with a large load as multiple clients try to reload the missing data simultaneously (a "cache stampede").
Implement a mechanism (e.g., using locks or a probabilistic cache update approach) to ensure that only one request attempts to refresh the expired/missing key from the database, while others wait or serve slightly stale data.
Use Consistent Hashing/Failover:
Employ a Memcached client library that supports consistent hashing (like Pylibmc or the python-memcached client) or client-side failover. This distributes keys more evenly and minimizes the number of cache misses when an instance goes down, as the client can map the keys to a different available server.
Bring up a new instance of Memcached on a new machine using the IP address of the lost machine, allowing the application to reconnect quickly.
Code Flexibility:
Write code that allows you to modify the Memcached server list with minimal work (e.g., loading the server list from a configuration file or environment variables) so that failed servers can be quickly removed or replaced.
Set Timeouts:
By setting a reasonable timeout value in your Memcached client, you prevent clients from indefinitely sending requests to a degraded server, which could block threads and hurt overall application performance. If a server is too slow, the client will time out and proceed to the next step (e.g., hit the database) quickly.

Program to return group of elements from list if their sum = 10
Answer: A program using a recursive backtracking approach to find all unique combinations of elements in a list that sum up to a target value.
Python
def find_sum_groups(nums, target_sum):
    result = []
    current_group = []
    # Sort the list to handle duplicates and speed up: nums.sort()

    def backtrack(start_index, current_sum):
        if current_sum == target_sum:
            # Found a group, append a copy
            result.append(current_group[:])
            return
        elif current_sum > target_sum:
            return

        for i in range(start_index, len(nums)):
            current_num = nums[i]
            current_group.append(current_num)
            # Recursive call: start from the next index (i + 1) to avoid re-using elements
            backtrack(i + 1, current_sum + current_num)
            current_group.pop() # Backtrack: remove the last element

    backtrack(0, 0)
    return result

def count_overlapping_substring_occurrences(main_string, substring):
    count = 0
    start_index = 0

    while True:
        # Find the next occurrence, starting the search from start_index
        start_index = main_string.find(substring, start_index)

        if start_index == -1:

        # Move to the next character (start_index + 1) for potential overlapping occurrences
        start_index += 1

This function prints the longest palindrome subString
Answer: A program using a brute-force approach to find the longest palindrome substring.
Python
# Helper function to print a substring from index low to high (inclusive)
def printSubStr(s, low, high):
    print(s[low: high + 1], end="")

def longestPalSubstr(string):
    n = len(string)

    # All subStrings of length 1 are palindromes
    maxLength = 1
    start = 0

    # Nested loop to mark start (i) and end (j) index of the substring
    for i in range(n):
        for j in range(i, n):
            flag = 1 # Assume it is a palindrome

            # Check for palindrome from both ends inwards
            # k runs from 0 up to the midpoint
            for k in range(0, ((j - i) // 2) + 1):
                if (string[i + k] != string[j - k]):
                    flag = 0 # Not a palindrome
                    break

            # If it is a palindrome and longer than the current max
            if (flag != 0 and (j - i + 1) > maxLength):
                start = i
                maxLength = j - i + 1

    print("Longest palindrome substring is: ", end="")
    printSubStr(string, start, start + maxLength - 1)

    return maxLength

How do you copy an object in Python?
Answer: In Python, the assignment statement (= operator) only creates a binding (another reference) to the existing object, it does not create a copy. To create copies of an object, you need to use the copy module.

Linked List implementation using Python:
Answer: A complete implementation of a Singly Linked List in Python demonstrating common operations:
Python
# Node class definition
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

# LinkedList class definition
class LinkedList:
    def __init__(self):
        self.head = None

    # Method to add a node at the beginning of LL
    def insertAtBegin(self, data):
        new_node = Node(data)
        new_node.next = self.head
        self.head = new_node

    # Method to add a node at any index
    def insertAtIndex(self, data, index):
        if index == 0:
            self.insertAtBegin(data)
            return

        current_node = self.head
        position = 0
        while current_node is not None and position < index - 1:
            current_node = current_node.next
            position += 1

        if current_node is not None:
            new_node = Node(data)
            new_node.next = current_node.next
            current_node.next = new_node
        else:
            print("Index not present")

    # Method to add a node at the end of LL
    def insertAtEnd(self, data):
        new_node = Node(data)
        if self.head is None:
            self.head = new_node
            return

        current_node = self.head
        while current_node.next:
            current_node = current_node.next
        current_node.next = new_node

    # Update node of a linked list at a given position
    def updateNode(self, val, index):
        current_node = self.head
        position = 0
        while current_node is not None and position != index:
            current_node = current_node.next
            position += 1

        if current_node is not None:
            current_node.data = val
        else:
            print("Index not present")

    # Method to remove first node
    def remove_first_node(self):
        if self.head is not None:
            self.head = self.head.next

    # Method to remove last node
    def remove_last_node(self):
        if self.head is None or self.head.next is None:
            self.head = None
            return

        current_node = self.head
        while current_node.next.next is not None:
            current_node = current_node.next
        current_node.next = None

    # Method to remove node at a given index
    def remove_at_index(self, index):
        if self.head is None:
            return
        if index == 0:
            self.remove_first_node()
            return

        current_node = self.head
        position = 0
        while current_node is not None and position < index - 1:
            current_node = current_node.next
            position += 1

        if current_node is not None and current_node.next is not None:
            current_node.next = current_node.next.next
        else:
            print("Index not present")

    # Method to remove a node by data value
    def remove_node(self, data):
        current_node = self.head

        if current_node is not None and current_node.data == data:
            self.remove_first_node()
            return

        prev = None
        while current_node is not None and current_node.data != data:
            prev = current_node
            current_node = current_node.next

        if current_node is None:
            return # Data not found
        else:
            prev.next = current_node.next

    # Print the size of linked list
    def sizeOfLL(self):
        size = 0
        current_node = self.head
        while current_node:
            size += 1
            current_node = current_node.next
        return size

    # Print method for the linked list
    def printLL(self):
        current_node = self.head
        while current_node:
            print(current_node.data)
            current_node = current_node.next

llist = LinkedList()

# add nodes to the linked list

llist.insertAtEnd('b')

Python Global Interpreter Lock (GIL)?
Answer: The Python Global Interpreter Lock (GIL) is a mutex (a lock) that allows only one thread to execute Python bytecode at a time, even on multi-core processor systems.
Purpose: The GIL is used to protect access to Python objects, preventing multiple threads from simultaneously modifying shared data structures, which simplifies memory management and prevents race conditions.
Effect: It effectively prevents true parallelism for CPU-bound tasks in standard CPython (the default implementation).
Release: The GIL is released during I/O operations (like file reading, network communication, or system calls) so that other threads can run while one is waiting, making multithreading still useful for I/O-bound tasks.
