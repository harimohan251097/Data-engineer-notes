What are Bad / Corrupt Records?
Records that:
Don’t match schema
Have wrong data types
Malformed JSON/CSV
Missing columns
 
Using mode("PERMISSIVE"):
Spark does NOT fail
👉 Stores bad records in a special column
df = spark.read \
.option("header", True) \
.option("mode", "PERMISSIVE") \
.option("columnNameOfCorruptRecord", "_corrupt_record") \  # new column created
.schema(schema) \
.csv("path/to/file") 

Extract Only Bad Records:
bad_df = df.filter(df["_corrupt_record"].isNotNull())
bad_df.show() 
 
Extract Good Records:
good_df = df.filter(df["_corrupt_record"].isNull()) 
 
Using mode("DROPMALFORMED"):
Drops bad records, kept only valid 
df = spark.read \
    .option("mode", "DROPMALFORMED") \
    .schema(schema) \
    .csv("path")
 
Using mode("FAILFAST"):
Immediately throws an error if any malformed record is found.

CONDITIONAL LOGIC (when clause ):

Basic condition: decide adult or young 
from pyspark.sql.functions import when, col

df = df.withColumn(
    "category",
    when(col("age") > 25, "Adult").otherwise("Young")
)

 Multiple conditions: grade base on marks
 df = df.withColumn(
    "grade",
    when(col("marks") >= 90, "A")
    .when(col("marks") >= 75, "B")
    .when(col("marks") >= 60, "C")
    .otherwise("Fail")
)

 Use expressions inside when(): salary flag on above 50000
df = df.withColumn(
    "salary_flag",
    when(col("salary") >= 50000, 1).otherwise(0)
)

 when + isNull(): name or unknown value 
df = df.withColumn(
    "name_clean",
    when(col("name").isNull(), "Unknown").otherwise(col("name"))
)

 Combine multiple conditions:
df = df.withColumn(
    "status",
    when((col("age") > 18) & (col("salary") > 30000), "Valid")
    .otherwise("Invalid")
)
 Or
df = df.withColumn(
    "status",
    when((col("age") > 18) | (col("salary") > 30000), "Valid")
    .otherwise("Invalid")

MERGE in PySpark:
MERGE is mainly used with Delta tables for handling incremental data updates
MERGE is used to update, insert, or delete data in a table based on a condition
 
Existing table (target)
id | name | salary
1  | Hari | 5000
2  | Mohan| 6000 
New data (source):
id | name | salary
2  | Mohan| 7000   ← updated
3  | Ravi | 4000   ← new 
 
Without MERGE:
Update existing rows
Insert new rows
Very complex 
 
With MERGE:
deltaTable.alias("t").merge(
    source_df.alias("s"),
    "t.id = s.id"
).whenMatchedUpdate(set={
    "salary": "s.salary"
}).whenNotMatchedInsertAll().execute()

 To get the last month of recordings in PySpark using a window function 
# 1. Convert timestamp to Unix seconds (Long) 
df = df.withColumn("unix_time", F.col("timestamp_col").cast("long")) 

# 2. Define 30 days in seconds seconds_in_month = 30 * 24 * 60 * 60 

# 3. Create window: look back 30 days from the current row's timestamp window_spec = Window.partitionBy("user_id").orderBy("unix_time") .rangeBetween(-seconds_in_month, Window.currentRow) 

# 4. Use window to aggregate or identify records # Example: Count recordings in the last month for each row 
df_result = df.withColumn("recordings_last_month", F.count("record_id").over(window_spec))
